## Where the signal comes from: four classes of feedback {#sec:signal}

Four scaffolds all run the loop of Section REF(sec:loop). A coding agent changes one line in its repository rule file; the test suite runs and reports pass or fail within seconds. A scheduling assistant changes how it phrases a booking request; the appointment either appears on the calendar or it does not, and the system learns which an hour later. A marketing assistant changes the tone rule in its instructions; nobody can say whether the next draft is better, only whether a reviewer prefers it. A research assistant changes how it chooses which direction to pursue; whether the choice was good becomes visible months later, after many other edits have landed. All four produce a candidate edit $z_t$. They differ in what the gate $G_t$ can know about it.

The gate accepts an edit when its estimate $\widehat{\Delta}_{z_t} L_D$ of the loss change clears a margin. Condition 1 asks for a measurable patch loss without saying what produces that estimate. We distinguish four classes of feedback signal by what produces it, and the class fixes three things at once: what the gate can be, which pairings of gate types a deployment can reach, and which failure dominates (Table REF(tab:IV-1)).

**C1, exact.** A deterministic checker returns pass or fail, or an exact score, immediately and repeatably: unit tests, compilers, type checkers, exact-match answer keys, proof checkers, schema validators. DGM accepts a self-modification only after it passes in a sandbox on coding benchmarks [@zhang2025darwin]; AlphaEvolve scores candidate programs with a cascade of exact evaluators [@alphaevolve2025]; SkillOpt gates a skill edit on a held-out exact-match split of a math benchmark [@yang2026skillopt]. The estimator bias $\varepsilon_t$ is close to zero, the margin $\tau_t$ can sit near zero, and accepting on a single evaluation is defensible, because repeating the check would return the same answer. Two things stay hard. A failing test localizes the output, not the scaffold coordinate that caused it, so credit assignment remains open; and a checker that is also the training target can be gamed. The dominant failures are test overfitting and scaffold bloat, because cheap acceptances accumulate.

**C2, observable outcome.** The environment or the user emits an outcome after an episode: a booked appointment, a closed ticket, a merged pull request, a tool call that returns without error, a retrieved document that contains the answer. The signal is real but one episode late, noisy, and confounded, since a user can accept a wrong answer and reject a right one. Gates of this class include Devin's merged pull requests [@cognition2025devinreview], SAGE's task success on AppWorld [@wang2025sage], SkillRL's success-rate threshold [@skillrl2026], and PACE's failure signals from a deployed small model [@ling2026pace]. The gate becomes a reinforcement-learning threshold or a held-out task suite with a strictly positive margin, and the noise is absorbed by batching episodes or by requiring agreement across samples (Appendix REF(app:gates)). Credit assignment takes its hardest form: the outcome says *that* the episode failed, not *why*. Most production deployments live in this class, and its signal arrives through a channel an attacker can control, which is why poisoned memory and tool-output injection dominate.

**C3, judged.** There is no fact of the matter. An essay, a marketing page, a blog post, a design, a pitch deck, or a code review for style can be scored only by a judge: a human rater, a language-model judge, a rubric, or a comparison against references. SkillForge accepts a skill diff when its judge agrees with human engineers more than nine times in ten [@skillforge2026]; CASCADE consolidates memory under a human-and-agent gate [@huang2025cascade]; Anthropic's skills repository promotes a skill when a reviewer approves the pull request. Three things change. The estimator bias $\varepsilon_t$ becomes the judge's bias, bounded only by calibration against people, so the bounded-bias assumption of Appendix REF(app:formal) has to be bought rather than assumed. Residuals are captured only when someone objects, so condition 2 depends on complaint channels rather than instrumentation.

The third change defines the class: the rubric that sets the loss is itself a scaffold coordinate. Suppose a pitch-review system keeps overrating decks that claim a large market without numbers. It traces the failure to its rubric and edits "evaluate market size" into "require a numeric estimate and a source". That edit changes the gate that will judge the next edit. We call this the *reflexive gate*. Its dominant failure is Goodhart's law in the form measured for reward models, where optimizing a proxy past a point lowers the true score [@gao2023overoptimization]: once the judge is the target, the scaffold learns the judge. Nor is a human judge stable; evaluators' criteria drift as they grade more outputs [@shankar2024validators].

**C4, delayed and sparse.** The outcome arrives after weeks or months, once per many edits, in a world that has moved on. Research programs, product strategy, and open-ended discovery are of this kind. The clearest instances are automated research pipelines such as the AI Scientist, which generates ideas, runs experiments, and writes the paper [@lu2024aiscientist]. NanoResearch merges candidate skills by semantic compatibility rather than by a measured loss change [@xu2026nanoresearch]; CORAL promotes findings into shared memory on a heartbeat rather than on an evaluation [@qu2026coral]; AlphaEvolve's MAP-Elites archive keeps candidates for their diversity, not their score [@alphaevolve2025]. With no per-edit estimate to gate on, $G_t$ degenerates to proposal pruning plus proxy milestones, and the descent argument covers only the composition of pruning and whatever gate exists at the horizon (Appendix REF(app:gates)). Temporal credit assignment across many edits is open. The dominant failure is drift: the scaffold ages faster than the signal that would correct it. An optimizer in this class also cannot be told from random search by its outcomes alone; Ong et al. [@ong2026harnesseval] report the same indistinguishability for harness optimizers.

**The same classes on the weight side.** Reinforcement learning from verifiable rewards trains weights on exact signals and lies outside the scored corpus, but pushing it into writing and other open-ended tasks has forced the construction of judged gates, the only ones a C3 scaffold loop can borrow. One group holds the gate fixed while the policy learns, as an instance-specific checklist, a pairwise judge trained on writing principles, a reference-anchored judge, or a fixed rubric of binary items [@gunjal2025rubrics; @jia2025writingzero; @shi2026references; @jin2026rlaes]. A second group lets the gate move with the policy, scoring by the policy's own probability of a fixed reference or updating the rubric or judge during training [@yu2025rlpr; @xu2026rubricarm; @ding2026evorubrics; @zhu2026score; @li2026rubricem]. Fixed versus co-evolved is exactly the reflexive-gate question. Of the co-evolving methods, only RLPR, whose reward is a probability rather than a rubric, reports agreement with human labels; none that co-evolves a rubric or judge does (Supplementary Material S6). On the scaffold side three systems report judge calibration [@skillforge2026; @hu2026skillchain; @zhu2026skillcoach], and none calibrates a judge that is itself being edited.

**What the class predicts.** If the class fixes the gate, the occupancy of the design space is no accident, and three predictions follow, which Section REF(sec:design) checks. First, an [Auto × Auto] system whose gate estimates the loss change per edit should run on a C1 signal or a simulated C2 environment, where outcomes are cheap to observe, and one that works on a C4 signal should prune proposals rather than estimate. Second, [Auto × Human] should hold only C2 and C3 systems, because the human on Loop 2 substitutes for the exact signal that Loop 1 lacks. Third, no scaffold system should yet calibrate a judged gate under the reflexive condition.
