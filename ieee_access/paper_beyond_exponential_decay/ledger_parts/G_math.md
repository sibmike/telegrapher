- Use 1 — our sentence (App. A, Union Bound and Positive Dependence): failure indicators "associated" = every pair of nondecreasing functions has nonnegative covariance; for two positions reduces to nonnegative correlation; success indicators then associated; P(all succeed) >= product of marginals [Th. 4.1].
  - Source passage: "DEFINITION 1.1. We say random variables T1, ..., Tn are associated if Cov[f(T), g(T)] >= 0 for all nondecreasing functions f and g" — p. 1466. "(BP1) If X1, ..., Xn are associated binary random variables, then 1 - X1, ..., 1 - Xn are associated binary random variables." — p. 1470. "THEOREM 4.1. Let X1, ..., Xn be associated binary random variables. Then P[X1 = 1, ..., Xn = 1] >= P[X1 = 1] ... P[Xn = 1]" — p. 1470. "THEOREM 4.2. For binary random variables X, Y, association is equivalent to Cov[X, Y] >= 0." — p. 1470.
