# Paper sources

The canonical Telegraph English paper and its supporting analyses, in source-of-truth Markdown.

| File | What's inside |
|---|---|
| [`telegraph_english.md`](telegraph_english.md) | The full preprint: grammar, methodology, benchmarks, results, discussion. |
| [`approach.md`](approach.md) | Extended notes on the design choices behind the TE grammar. |
| [`benchmark_outcomes.md`](benchmark_outcomes.md) | Headline benchmark results and what they show. |
| [`benchmark_analysis.md`](benchmark_analysis.md) | Deeper analysis of compression behaviour across models and document types. |

The arXiv-formatted PDF builds from `telegraph_english.md` and lives at [`../arxiv/paper_telegraph_english/`](../arxiv/paper_telegraph_english/). The NeurIPS-formatted version lives at [`../neurips/paper_telegraph_english/`](../neurips/paper_telegraph_english/).

For the project overview, headline numbers, and how to run the pipeline, see the [main repository README](../README.md).
